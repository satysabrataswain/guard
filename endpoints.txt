1. AUTHENTICATION
=================
Base: /api/auth/

POST  /api/auth/register/
      New user registration

POST  /api/auth/login/
      User login + JWT token

POST  /api/auth/token/refresh/
      Refresh JWT access token

GET   /api/auth/me/
      Get current logged-in user

POST  /api/auth/logout/
      Logout


2. THREAT DETECTION
===================
Base: /api/threats/

GET/POST  /api/threats/
          List threats / create threat

POST      /api/threats/analyze/
          Main threat analysis endpoint

GET       /api/threats/<id>/
          Get threat details

DELETE    /api/threats/<id>/delete/
          Delete threat


3. PHISHING
===========
Base: /api/phishing/

POST  /api/phishing/url/analyze/
      Analyze URL for phishing/malicious indicators.
      Includes URL shortener and redirect-chain inspection.

POST  /api/phishing/email/analyze/
      Analyze phishing email.

GET/POST  /api/phishing/history/
          Get/create phishing scan history

GET  /api/phishing/<id>/
     Get phishing scan details

DELETE  /api/phishing/<id>/delete/
        Delete phishing scan

6. INCIDENTS & RESPONSE
=======================

          List incidents / create incident

GET       /api/incidents/<id>/
          Get incident details

DELETE    /api/incidents/<id>/delete/
          Delete incident

          Get/add incident evidence
